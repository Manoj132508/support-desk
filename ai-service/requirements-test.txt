# deterministic fakes and assert on the decisions and the prompt -- which is
# where the logic lives. sentence-transformers and chromadb are imported
# lazily, inside constructors, so importing any module here costs nothing.
#
# The trade is stated plainly: CI proves the pipeline's logic in seconds. It
# does not prove that a real model embeds these documents usefully. That is an
# integration concern, and Phase 13's eval is where it is measured.
